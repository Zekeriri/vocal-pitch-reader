# 音高朗读

一个在浏览器里本地运行的单音练习工具。你唱一个音，它稳住之后把音名念出来，例如 `G3`。计算和朗读都在你自己的电脑上，声音不会上传。

它只认一个人、没有伴奏的单音。这是替代 Estill Voiceprint 里“看右上角音高”的轻量做法，不包含频谱、共振峰或其他声部分析。

## 一键启动和关闭

需要已安装 Node.js 22 或更新版本。在资源管理器中打开项目文件夹：

- 双击 `start.bat` 启动。第一次会安装依赖，然后自动打开浏览器。
- 双击 `stop.bat` 关闭。

页面地址是 [http://127.0.0.1:8741](http://127.0.0.1:8741)。已经在运行时再双击 `start.bat`，只会重新打开这个页面。

同一份步骤也写在 `使用说明.txt` 里。

## 命令行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:8741](http://127.0.0.1:8741)。点「开始听」，允许麦克风，戴上耳机再唱。

「试听 G3」会弹出钢琴的 G3，用来确认检测和朗读是否工作，不需要麦克风。

```bash
npm test
npm run build
```

## 怎么用

- 唱稳大约 0.3 秒才念一次。时间可以在顶部「设置」里改，几个练习共用。
- 颤音只要还在这个音附近，不会来回改口。
- 滑音很快经过的音不会每个都念。
- 停大约半秒再唱，同一个音会再念一次。
- 请戴耳机。扬声器里的朗读如果被麦克风听到，会干扰判断。

## 咽音练习

页面顶部可以切到「咽音练习」。里面有哼鸣和灵活性两套音阶。哼鸣做到第 11 组，灵活性做到第 13 组。

点「播放并跟唱」会先把这一组音阶播出来。播完再唱。点「下一组」会换到下一组，并直接开始播放并跟唱。最高音要稳住「设置」里的那段时间才记下来。唱完停一下就念出来，并告诉你有没有到这一组的最高音。

## 音准训练

页面顶部的「音准训练」一轮弹 10 个音。最低音和最高音可以自己选，默认从 C3 到 C5，可选范围是 A2 到 C5。每个音先听，再唱。先稳住「设置」里的那段时间，再判断。和弹出的音差在 25 音分以内才算过，然后弹下一个。偏低会提示「低了」，偏高会提示「高了」。十个都准，这一轮过关。

## 颤音

页面上的「颤音」有两步。练习 1 选元音 a i u e o，再选头声假声或真声胸声。音高自己定。然后开口颤，屏幕数这一口气里颤了几次，满 7 次可以收，9 次是一轮。练习 2 看频率：慢速 3～4 次/秒，中速 4～5，快速 5～6，超快 6 次以上。从慢速开始，稳住再加快。曲线是音高的起伏。

## 环倾

页面上的「环倾」从 C4 到 C5，一个音一个音练，三个练习用同一串音。唱的时候显示现在的音高。结束以后留下稳住的最高音，稳住时间和咽音练习一样。短音下滑用真声，碰一下当前这个高音再滑向低音，高音不超过 1 秒。短音重复在这个音上至少做三次。长音在这个音上站住，超过 1 秒。

## 时之笛

页面上的「时之笛」先按游戏里的拍子把六个音弹出来。摇篮曲是一拍一个音、每分钟 100 拍，伊波娜之歌是每分钟 96 拍。然后你从任意音高把这句哼出来。图上的格子是旋律形状，圆点是你现在的音高。音和音之间差在一个半音以内就算对，高八度或低八度也算。哼错就从头再来。

现在有两首，都是游戏里那六个音：

- 塞尔达摇篮曲：B4 D5 A4 B4 D5 A4
- 伊波娜之歌：D5 B4 A4 D5 B4 A4

## 设置

顶部最后一项是「设置」，「时之笛」在它前面。语音提示默认开着，会念出音名，以及「高了」「低了」「过关」「学会了」。关掉以后，音名和这些话还写在屏幕上。音准训练、咽音练习、环倾和时之笛里弹出的是 Salamander Grand Piano 采样（Alexander Holm，CC BY 3.0）。钢琴音量和每个音响多久可以在这里调。稳住时间和响度门限也在这里，几个练习一起用。电平条上的白点是响度门限。房间吵、条一直亮着却乱念时，把门限往右拨。颤音数的是音高起伏，不停下来等稳住。环倾从 C4 走到 C5。短音下滑的高音不超过 1 秒，长音超过 1 秒就行。

空格键可以开始或停止聆听。

## 放到 GitHub Pages

GitHub 会自动提供 HTTPS，不用自己装证书。iPad 打开发布出来的网址就能用麦克风。免费账号需要把这个仓库设成公开。

1. 在 GitHub 新建一个公开仓库，不要勾选添加 README。仓库名可以是 `vocal-pitch-reader`。
2. 在项目目录执行（把用户名和仓库名换成你的）：

```powershell
git remote add github https://github.com/你的用户名/vocal-pitch-reader.git
git push -u github main
```

3. 打开该仓库的 Settings → Pages。Build and deployment 的 Source 选 GitHub Actions，保存。
4. 打开 Actions，等 Deploy GitHub Pages 变成绿色。站点地址是 `https://你的用户名.github.io/vocal-pitch-reader/`。

以后改完代码，再执行 `git push github main`，页面会自动更新。iPad 用浏览器打开上面的 https 地址，点「开始听」。

## 局限

- 有伴奏、合唱，或同时有两个人出声时，音高会乱。
- 气声很重、声音很轻时，可能要再唱稳一点，或把门限调低。
- 浏览器切到后台后，个别系统会放慢页面。练习时让这个标签页保持打开。
- 朗读用的是系统语音。它会尽量选英语声音来读 `G 3`、`G sharp 3`。
