音高朗读

一键启动
  双击 start.bat
  第一次会安装依赖，稍等。浏览器会自己打开 http://127.0.0.1:8741/

一键关闭
  双击 stop.bat

使用
  1. 戴上耳机。
  2. 点「开始听」，允许麦克风。
  3. 唱稳大约 0.3 秒，电脑会念出音名，例如 G3。
  4. 停大约半秒再唱，同一个音会再念一次。
  5. 不想出声时，点「试听 G3」检查是否正常。

房间吵、它乱念时，打开顶部的「设置」，把门限往右拨。弹出的音是 Salamander 钢琴采样。钢琴音量和每个音的长度也在设置里调。稳住时间和响度门限对各个练习都生效。
空格键可以开始或停止聆听。
请让浏览器这个标签页留在前台。

咽音练习在页面顶部切换。选哼鸣或灵活性，点「播放并跟唱」。音阶播完再唱。点「下一组」会自动把下一组音阶播一遍。最高音要稳住设置里的那段时间才记，唱完会念出来。

音准训练也在页面顶部。先选最低音和最高音，点「开始」后先听一个音，再唱成同一个音。准了才到下一个，偏低提示低了，偏高提示高了。连续十个都准就过关。

时之笛在页面顶部。选塞尔达摇篮曲或伊波娜之歌，再用音域把整首调低，点「开始」。先听完整首，再一个音一个音哼，稳住了才算过。默认是 A3 到 D4。

需要已安装 Node.js 22 或更新版本：https://nodejs.org/

放到 GitHub Pages 之后，iPad 打开 GitHub 给出的 https 地址即可使用。步骤写在 README.md 的「放到 GitHub Pages」。
